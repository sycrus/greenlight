# OpenSpec

This directory contains OpenSpec changes for Greenlight v0.1.

## Active changes

Changes in progress live in `changes/`. Completed changes are archived to `archive/`.

## Workflow

```
/opsx:explore              Explore the problem space
/opsx:propose <change>     Create proposal + specs + design + tasks
/opsx:apply                Implement tasks
/opsx:archive              Archive completed change, update specs
```
